# Kraken's Lair — raster art drop folder

Place generated assets here. The game auto-loads them and falls back to SVG if a file is missing.

```
assets/
  background.webp          # 16:9 stormy ocean scene
  reel-frame.webp          # vault border (transparent center)
  hero-kraken.webp         # bonus cinematic key art
  symbols/
    rope.webp
    barnacle.webp
    anchor_chain.webp
    wheel.webp
    compass.webp
    spyglass.webp
    map.webp
    bell.webp
    skull.webp
    crown.webp
    chest.webp
    wild.webp
    scatter.webp
```

PNG works too (`.png` tried after `.webp`).

Full generation prompts: `docs/art-generation-prompts.md`
